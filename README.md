# XR18 Bubble website

The static site source is in this directory. It needs no build step, JavaScript, cookies, analytics or external fonts.

The public destination is https://palkoskoda.github.io/xr18-bubble/ with the privacy policy at privacy.html. Publication uses the root of the gh-pages branch, separate from the Android sources on main.

Deploy only index.html, privacy.html, styles.css, icon.png and .nojekyll to gh-pages. Update the actual beta download link when publishing a new APK. Keep Wi-Fi profiles, signing keys and generated logs out of both branches.
