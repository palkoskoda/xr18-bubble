# Release notes

## 0.4.1-beta

- Seven control sizes: Small, Medium, Large, Extra large (XL), Very large (2XL), Huge (3XL) and Maximum (4XL).
- Larger sizes enlarge control labels and values, fader handles, signal meters and mute buttons. The panel scrolls horizontally between controls and vertically when needed on a smaller screen.
- Drag the collapsed bubble onto the bottom **×** target to stop the floating controller. Release elsewhere to keep it running at the nearest screen edge.
- The new size names and guidance are available in all twelve app languages. Bubble size retains its three existing choices.

This beta uses Android version name 0.4.1 and version code 6. For verification results and remaining device coverage, see [Testing](../TESTING.md).

## 0.4.0-beta

First public beta with configurable floating mixer controls, live signal meters, saved mixer Wi-Fi requests and return actions, an app shortcut, themes and twelve offline interface languages. Distributed through GitHub Releases.
